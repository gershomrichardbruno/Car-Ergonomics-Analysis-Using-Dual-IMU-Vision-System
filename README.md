# Car Ergonomics Analysis Using Dual IMU-Vision System

## 🚗 Project Overview

This project focuses on developing a **portable biomechanical analysis system for car seating ergonomics** using an integrated **IMU and computer vision approach**.

The system analyzes human posture and movement during **car entry, seating, adjustment, and exit**. It aims to evaluate seating comfort, identify potentially harmful movement patterns, and provide data-driven insights for improving automotive ergonomics.

## 🎯 Objectives

* Analyze movement during car entry, seating, and exit.
* Estimate joint angles and posture changes.
* Develop an integrated posture estimation system.
* Validate IMU measurements using computer vision.
* Identify ergonomic risks and potentially harmful movements.
* Support improved automotive seating design.

## ⚙️ Methodology

The project follows a **dual-system methodology** combining IMU-based motion analysis with computer vision-based pose estimation.

### IMU-Based Analysis

IMU data are collected from different body segments during car seating movements. The acquired signals are processed to determine body-segment orientation and joint movement.

### Computer Vision Analysis

A side-view camera records the subject during movement. Pose estimation is used to identify body landmarks and calculate biomechanical joint angles.

### Integrated Validation

Measurements obtained from the IMU system are compared with computer vision estimates to assess agreement, reliability, and measurement accuracy.
